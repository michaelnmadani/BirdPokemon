# Read-only showcase

`showcase.json` is the collection shown at `<site>/view/` — a read-only copy
of the app (Collection, Field Guide, Sightings) for linking from a website.

To update it: in the app open **Settings → Showcase → Export my collection**,
then replace this file with the exported `showcase.json` and push. The export
holds each sighting's species, date and a small thumbnail — no locations or
notes.

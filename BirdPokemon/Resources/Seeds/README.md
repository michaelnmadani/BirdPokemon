# Bundled seed files

These JSON files ship inside the app so the catalog works offline on the
very first launch before Firestore sync completes.

- `taxonomy_<REGION>.json` — array of `Species` records for that region.
  Generated by exporting documents from `speciesCache` after running
  `scripts/seed-ebird/seed.ts --region <REGION>` and `enrich.ts`.

## Regenerating

```sh
cd scripts/seed-ebird
npm run seed -- --region AU
npm run enrich -- --region AU --avonet data/AVONET.csv --colors data/colors_AU.json
# Then export from Firestore to taxonomy_AU.json
```

The AU taxonomy shipped at launch is a minimal 8-species hand-picked seed
so the app runs end-to-end before you've set up Firebase. Replace it with
the full ~900-species AU export once your seed pipeline has been run.
